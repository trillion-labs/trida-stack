# Draft-aligned fine-tune of the noisy stream (self-distillation) — run spec

**Goal.** Raise self-spec (AR-Trust) acceptance from ~2.3 tokens/forward toward DFlash-level (~6) with zero extra
parameters, by training the noisy stream on what the verifier actually scores: the clean stream's own greedy
continuation, on the decoder's real canvas, at the decode block size.

**Why (evidence).** v6-2n trains random-mask reconstruction of dataset tokens over 32-token blocks (AR weight 0.1);
inference asks the noisy stream to fill `[t, MASK×(N−1)]` with the clean stream's next tokens. Accept-count histogram at
N=4 is bimodal (45% accept 0, 33% accept 3). DFlash's separate 6-layer drafter, trained against its target, accepts 6.5/16;
same GPU, same protocol: DFlash b16 2.4× (vLLM) / 3.5× (SGLang) vs self-spec 1.6× at C=1 — the whole gap is acceptance.

## Data (`train/tools/draftalign/gen_selfdistill.py`, job `gen_job.sh`)
- Source prompts: `$SCRATCH/dataset/diffusion-agent/v6` (700k conversations, 45% multi-turn, tools/tool results),
  every 17th row → ~40k conversations, all assistant turns (~140k).
- Each assistant turn regenerated by step_18000 **AR greedy**, thinking on, teacher-forced on the ORIGINAL history
  (prompt = trainer's own `_apply_template(messages[:i], tools, add_generation_prompt=True, keep_all_reasoning=True)`
  → token ids → vLLM `/v1/completions`, `max_tokens 16384`, temperature 0). Turns that hit the cap → the whole
  conversation is dropped (no truncated targets). Generated text stored as the assistant `content` (the template re-splits
  `<think>…</think>` itself); per-turn round-trip check (re-render == prompt+generated ids), mismatch rate logged.
- Output: `luke/models/scratch/data-draftalign-v1/shard-n{0,1}.jsonl` (v6 schema + `meta.generated`).
- Servers: 16 stock vLLM AR replicas (step_18000, max-num-seqs 16, max-model-len 32768), two nodes; ~1–2 h.

## Trainer change (`train/hf_block_diffusion_hybrid.py`)
- New flag `--mask_pattern canvas` (default `random` = unchanged behaviour). In `_make_flare_views`: blocks of `bd_size`
  aligned to each assistant turn (from `resp_block` when available), and per block a **masked suffix** of m slots,
  m ∈ {1..bd−1} with P(m=bd−1)=0.5 (cold start) and the rest uniform — the decoder's canvas states. Single view
  (complementary masks are meaningless for suffixes); `forward_flare` becomes V-agnostic; rate=1 (uniform weighting).
- Nothing else changes: same two-stream forward, token-shift readout, AR loss on the clean stream.

## Run
- `--model_id <step_18000>` (fresh optimizer; NOT `--resume`), `--bd_size 8 --ar_loss_weight 1.0 --mask_pattern canvas`,
  `--pack --multiturn --keep_all_reasoning`, 32k packing as before, LR 5e-6 constant (`--lr_min_ratio 1.0`), warmup 100,
  micro 1 × accum 2 × 16 GPUs. **300-step first look** (checkpoints at 150/300; ~4 passes over the ~30k generated
  conversations; 1500 steps would be >10 epochs), extend to 600 only if 150→300 improves. Weights-only saves.
- Save dir: `/path/to/models/scratch/trida-4b-draftalign-bd8/` (+ `RUN.json`: source ckpt, data hash, flags).
  hyungguk's tree is never written. Disk: ~30 GB checkpoints + ~2 GB data (261 GB free).

## Eval per checkpoint (existing Slurm tooling)
1. vLLM self-spec N=4 and N=8: tok/fwd from traces + accept-count histogram; C=1 and C=16 throughput.
2. SGLang AR-Trust g4/g8 (FLARE fork, after the `_sglang` conversion): tok/fwd.
3. Guard: AR greedy GSM8K (no-think) vs step_18000 — accuracy within 1 pt, identity not collapsing; else stop.

## Autopilot chain (Slurm dependencies, `train/tools/draftalign/autopilot_submit.sh`)
gen (3675) → main train → {step_150, step_300} × {vLLM self-spec N=4, N=8, AR guard} → control train (canvas masks on
original v6, same flags) → its evals. Each stage reviewed on notification; stop rules: AR accuracy −1 pt or identity collapse.

## Success
≥3.5 tok/fwd at N=8 with AR intact = clear win; ≥5 = DFlash territory at zero parameters; <3 = shared weights are the
limit → separate drafter is the honest next step. Decision after the 750-step checkpoint.
