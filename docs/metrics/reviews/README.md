# 기간 검토 기록

스냅샷은 숫자고, 이 디렉터리는 **그 숫자를 보고 무엇을 하기로 했는지**입니다.

측정만 쌓는 것과 측정이 결정을 바꾸는 것은 다릅니다. 한 기간이 끝날 때마다 파일
하나를 추가하고, 세 가지를 적습니다 — **무엇을 쟀나 / 무엇을 발견했나 / 무엇을
하기로 했나.** 바뀐 게 없으면 "바뀐 게 없다"고 적습니다. 그것도 결정입니다.

| 파일 | 기간 |
|---|---|
| [`2026-W42.md`](2026-W42.md) | 2026-10-13 측정 |

주간 워크플로는 스냅샷을 **PR로 올립니다.** 그 PR을 머지하기 전에 해당 기간의 검토
기록을 같은 PR에 추가합니다 — 숫자만 들어오고 검토가 비는 상태를 만들지 않기 위해서고,
그게 Lv3가 묻는 지점입니다.

## 주기

관찰 기간에는 **주간**입니다. 지표를 월 1회만 보면 수집이 잘못됐다는 걸 알아내는 데
한 분기가 걸립니다. 90일 기준선이 생기고 목표를 정한 뒤에는 월간으로 내립니다.

스냅샷은 저장소 전체 이력에 대한 누적값입니다. 주기는 그 누적값을 **얼마나 자주
적어두고 들여다보는지**만 정합니다.
