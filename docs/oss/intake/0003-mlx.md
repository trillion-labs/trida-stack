## Why we needed something here

An on-device path on Apple silicon, so the model can be run without a GPU box. This
is the only place in the stack where CUDA is not available, so it needs its own
array library and its own serving glue.

## Alternatives considered

| 후보 | 왜 선택하지 않았나 |
|---|---|
| PyTorch MPS backend | kernel coverage for the ops we need is incomplete, and performance is far from what MLX gets on the same hardware |
| llama.cpp / GGUF | would require a separate quantised export path and a second model contract to keep in sync |

## Decision

Adopt, as an optional backend. It must not become a required dependency of the core
package — a CUDA box and an Apple laptop should not need each other's dependencies.

## Obligations we take on

MIT attribution in [`NOTICE`](../../../NOTICE).

## Re-evaluation trigger

Annually, or if the on-device path stops being used — an unused optional backend is
maintenance cost without a return, and the record should then say so.
