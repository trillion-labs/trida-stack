# 외부 OSS 도입 평가서 — vLLM 0.27.x

> Record date 2026-09-30; documents the decision taken when the vLLM backend was built
> as an out-of-tree plugin rather than a fork. Written record dated today.

## 기본정보

- 신청 프로젝트: trida-stack `inference/vllm/`
- 후보명 / 버전 / commit: vLLM `0.27.*` (stock PyPI wheel, no source build, no fork)
- 공식 저장소·패키지 URL: https://github.com/vllm-project/vllm
- 사용 기능과 결합 방식: second serving backend. Registered as an **out-of-tree plugin**
  via the `vllm.general_plugins` entry point (`VLLM_PLUGINS=trida_diffusion`), providing
  the `Qwen3_5ForBlockDiffusion` architecture. We depend on the published wheel only.
- 배포 시나리오: 소스 (our plugin) + 바이너리 dependency (their wheel)

## 결정

- **결정: 승인**
- 승인 버전과 사용범위: `vllm==0.27.*`, pinned. Serving only.
- 조건·완화조치: the plugin must stay out-of-tree. A fork would mean carrying vLLM's
  release cadence ourselves, which is the cost this decision exists to avoid.
- 대체전략: SGLang backend already serves the same checkpoint and modes — genuine
  redundancy, not theoretical
- 재평가일과 트리거: 2026-12-31, or when moving off the 0.27 pin
- 승인자: Trillion Labs research team
