## 3. 좋은 사례 2건 · 막힌 사례 2건

**좋은 사례**

1. 커널 라이선스 처리 — 비상업 커널을 vendoring하지 않고 fetch 레시피로 전환한 결정이

2. PR #1에서 문서가 코드와 어긋난 사실("vendored")을 발견하고 수정했다. 신선한 clone이
   빌드되지 않는 상태였다.

**막힌 사례**

1. **HybridDiffusion이 자사 라이선스 정책의 치명 조건을 통과하지 못한다.** 상업 이용
   금지 조항 때문이며, 대체 구현이 없다. 두 개의 핵심 경로가 비상업 제약을 상속한다.
2. W&B API 키가 노출된 뒤 아직 교체되지 않았다. 공개 저장소에는 없으나 미조치 상태다.
