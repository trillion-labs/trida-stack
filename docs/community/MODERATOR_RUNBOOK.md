# Moderator runbook

모더레이션은 감정 노동입니다. 한 사람이 신고함을 계속 보지 않도록 당번을 운영하고,
심각한 사건 뒤에는 교대합니다.

## 신고 접수

1. **신고자 안전과 긴급성을 먼저** 확인한다.
2. 원문 URL, 시각, 채널, 증거를 **제한된 기록부**에 보존한다.
3. **이해충돌이 있는 운영자는 사건에서 빠진다** — 대체 검토자가 맡는다.
4. 공개 답변에 개인정보나 조사 내용을 노출하지 않는다.

신고자에게 결과의 모든 세부사항을 공개할 수는 없지만, **접수 여부·처리 상태·완료
여부·안전 지원 경로**는 알려줍니다.

## 등급과 조치

| 등급 | 예 | 기본 조치 |
|---|---|---|
| **S1** | 실수, 경미한 비생산적 표현 | 비공개 안내·수정 요청 |
| **S2** | 반복 스팸, 공격적 언행 | 공식 경고·일시 제한 |
| **S3** | 괴롭힘, 혐오, 고의적 방해 | 즉시 제한·운영진 검토 |
| **S4** | 신상 공개, 신체 위협, **자격증명 노출** | 긴급 차단·플랫폼 신고·보안/법무 에스컬레이션 |

**안전이 기술 토론의 완결성보다 우선합니다.** 신상 공개·신체 위협·자격증명 노출처럼
즉시 피해가 가능한 경우에는 콘텐츠 노출을 줄이고 계정을 제한한 뒤 조사합니다.

판단은 **사람의 평판이 아니라 관찰된 행동과 정책 조항**에 연결합니다. 일반적인 의견
충돌은 질문을 기술 사실로 되돌리고, 인신공격은 분리해 다룹니다.

## 사건 기록

- 사건 ID / 접수 시각 / 담당자
- 적용 정책 조항 / 확인한 사실과 URL
- 조치, 범위, 만료 시각 / 당사자 통지
- 이의제기와 재검토 결과 / 재발 방지 조치

필요 이상으로 대화 전체를 복제하거나 **민감정보를 운영자 개인 장치에 저장하지
않습니다.** 보존기간이 지나면 안전하게 삭제하고 열람 기록을 관리합니다. 사건 통계를
공개할 때는 개인을 재식별할 수 있는 작은 수치와 정황을 합칩니다.

## 기술적 반대와 행동 위반의 분리

정중한 반대는 **결정 기록에 남기고**, 모욕적 표현은 조정합니다. 운영자가 자신의 설계
결정을 비판한 사람을 직접 제재해야 하는 상황이면 **다른 운영자에게 검토를 요청합니다.**

GitHub Discussions의 잠금은 **불편한 비판을 숨기는 수단이 아닙니다.** 대화가
비생산적이거나 행동강령을 위반할 때 이유를 남기고 사용합니다.

## 질문을 자산으로 바꾸는 절차

채팅에서 받은 질문을 기준 시스템으로 올리는 8단계입니다. 이게 지켜지지 않으면 지식이
사라지고 [응답 지표](../metrics/README.md)도 조용히 틀립니다.

1. **환영** — 질문 의도를 한 문장으로 확인
2. **안전 확인** — 토큰·개인정보·미공개 취약점이 없는지
3. **분류** — 사용 질문 / 결함 / 아이디어 / 기여 협의
4. **명료화** — 버전, 환경, 기대·실제 결과, 재현 절차
5. **승격** — Discussion 또는 Issue를 만들고 채팅 원문과 연결
6. **소유** — 담당자와 다음 갱신 시점 표시
7. **종료** — 해결 버전·문서 링크를 남기고 **채팅에도 짧게 회신**
8. **재사용** — 세 번 반복된 질문은 FAQ나 문서 개선 이슈로

`#help`의 질문은 thread로 분리하고, 해결되면 **운영자가 세 문장으로 요약해 기준
Discussion/Issue를 연결합니다.**

## 개설 전 모의훈련

가이드가 요구하는 4가지입니다. 채널을 열기 전에 운영자끼리 해봅니다.

- [ ] 잘못된 채널의 버그 질문을 친절히 분류한다
- [ ] **토큰이 포함된 로그**가 게시되었을 때 노출 최소화와 폐기를 안내한다
- [ ] 반복 스팸 계정을 제한하고 사건 기록을 남긴다
- [ ] 담당자가 없는 **주말에 심각한 위협 신고**가 왔을 때 에스컬레이션한다

## 운영자 건강

야간 즉시 응답이 필요한 위험과 다음 영업일에 처리할 사안을 **구분합니다.** 운영시간을
측정해 커뮤니티 성장보다 빠르게 증가하면 채널 범위·자동화·인력 또는 **응답 약속**을
조정합니다. 응답 약속을 줄이는 것도 정당한 선택입니다.
